## TC-01: 页面加载测试

**前置条件**：用户已登录

**测试步骤**：
1. 访问语音速记页面
2. 检查页面元素

**预期结果**：
- [ ] 页面标题显示"语音速记"
- [ ] 显示副标题"说出你与联系人的交互，AI 自动整理归档"
- [ ] 显示紫色圆形录音按钮
- [ ] 按钮内有麦克风图标 🎙️
- [ ] 按钮文字显示"开始录音"
- [ ] 底部显示"💡 无法录音？点击手动输入"

## TC-02: 录音按钮样式测试

**测试步骤**：
1. 检查录音按钮外观
2. 检查按钮居中状态

**预期结果**：
- [ ] 按钮为圆形
- [ ] 按钮颜色为紫色渐变 (#6C5CE7 → #A29BFE)
- [ ] 按钮尺寸约 280rpx × 280rpx
- [ ] 按钮水平居中
- [ ] 麦克风图标清晰可见
- [ ] "开始录音"文字完整显示，无截断

---

## TC-03: 录音功能测试（需要麦克风权限）

**测试步骤**：
1. 点击"开始录音"按钮
2. 允许浏览器访问麦克风
3. 说话："今天和张三开会，讨论了新项目的时间安排"
4. 点击停止录音

**预期结果**：
- [ ] 点击后按钮变为红色，文字变为"停止录音"
- [ ] 显示"正在录音..."提示
- [ ] 录音结束后自动转录
- [ ] 显示转录文本区域
- [ ] 显示"重新处理"和"清空"按钮

---

## TC-04: 手动输入测试

**测试步骤**：
1. 点击"💡 无法录音？点击手动输入"
2. 在弹窗中输入："今天和李四通了电话，他说合同已经发到我邮箱了"
3. 点击确定

**预期结果**：
- [ ] 弹出输入框
- [ ] 输入后自动处理
- [ ] 显示 AI 提取结果

---

## TC-05: AI 提取结果展示测试

**前置条件**：已有转录文本

**测试步骤**：
1. 输入或录音一段包含联系人信息的文本
2. 等待 AI 处理完成

**预期结果**：
- [ ] 显示"AI 整理结果"卡片
- [ ] 显示📝摘要（50 字内）
- [ ] 显示⭐要点列表（如有）
- [ ] 显示⏰提醒（如有跟进事项）
- [ ] 显示👤识别到的联系人姓名、公司、职位

## TC-06: 保存语音笔记测试
