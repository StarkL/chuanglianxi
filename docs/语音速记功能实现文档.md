# 语音速记功能实现文档

> 更新日期：2026-10-10  
> 运行平台：PC 端 PWA / 移动端 PWA / H5（需安全上下文支持）

---

## 📋 功能概述

语音速记功能允许用户通过语音快速记录与联系人的交互，系统提供**端侧离线优先**的双引擎语音识别与智能提炼闭环：
1. **端侧离线语音识别 (SenseVoice-Small ONNX)** - 100% 音频本地处理，无需上传云端，彻底杜绝隐私泄露
2. **原生极速流式识别 (Web Speech API)** - 免下载模型，即开即用
3. **AI 结构化提取** - 本地/自托管大模型提取联系人、摘要、关键要点与提醒
4. **自动归档与落盘** - 自动关联联系人，本地通过 WebCrypto AES-256-GCM 强加密存储
5. **智能跟进提醒** - 自动生成后续跟进日程

---

## 🏗️ 技术架构

系统采用“端侧离线优先 + 浏览器原生兜底”的双引擎自适应架构：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        前端交互层 (PWA / H5)                           │
│  ┌───────────────────────────────┐  ┌───────────────────────────────┐  │
│  │    【引擎 1】端侧离线模式       │  │    【引擎 2】原生极速模式       │  │
│  │   (SenseVoice ONNX ASR)       │  │      (Web Speech API)         │  │
│  └───────────────┬───────────────┘  └───────────────┬───────────────┘  │
└──────────────────┼──────────────────────────────────┼──────────────────┘
                   ▼                                  ▼
┌────────────────────────────────────────────────────────────────────────┐
│                     端侧推理引擎 (Web Worker 隔离沙箱)                    │
│  1. 麦克风 PCM 采集 (16kHz 单声道 Float32Array)                         │
│  2. 音频特征工程：80维 Fbank + LFR (5帧堆叠步长1) + CMVN 归一化          │
│  3. ONNX Runtime WebAssembly (ort-wasm-simd-threaded.wasm) 多线程加速  │
│  4. 模型离线缓存：CacheStorage 持久化，首次拉取后支持纯断网运行           │
│  5. CTC Greedy 解码 + 自动逆文本正则化 (ITN) 还原标点与中英文排版       │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 转写纯文本 (音频数据 0 外发)
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   信息结构化与加密落盘 (业务逻辑层)                       │
│  1. 本地规则 / 自托管 AI 结构化提炼：提取联系人、摘要、要点、跟进提醒    │
│  2. 交互记录关联：支持手动选择或自动检索联系人                         │
│  3. WebCrypto AES-256-GCM 强加密写入底层 IndexedDB (明文绝不落地)        │
└────────────────────────────────────────────────────────────────────────┘
```

## 🚀 PC 端 PWA 与 HTTPS 实测验证

### 1. 安全上下文与 WebAssembly 多线程
* **依赖规范**：ONNX Runtime Web 多线程 SIMD 引擎（`ort-wasm-simd-threaded.wasm`）依赖浏览器的 `SharedArrayBuffer` 与 `crossOriginIsolated` 特性；
* **环境要求**：根据 W3C 安全规范，浏览器仅在**安全上下文 (Secure Context)** 即 `HTTPS` 或 `localhost` 环境下放开 `SharedArrayBuffer` 权限；
* **实测结果**：在 PC 端 PWA 独立桌面窗口（或基于 HTTPS 域名的生产环境）下测试通过：
  1. 模型首次拉取校验完整；
  2. 成功写入沙箱 `CacheStorage` 离线持久化；
  3. 录音完毕后在本地沙箱 Worker 线程内秒级完成 Fbank 特征提取与 CTC 推理转写；
  4. 提炼出的纪要与日程提醒成功落盘。

### 2. 弱网与异常自愈保护
* **Worker 初始化防卡死**：增加 60 秒加载超时保护与全链路错误信息冒泡透传，杜绝白屏与无响应假死；
* **非安全上下文降级处理**：当检测到直连 HTTP IP 或不支持 `SharedArrayBuffer` 的宿主环境时，系统友好弹窗提示并引导一键切换至【原生极速模式】。

## 🔒 隐私安全与自托管优势

作为注重隐私的个人开源 CRM 工具，离线语音速记具备如下核心优势：

1. **100% 数据不出端**：
   - 音频采集、特征转换、模型推理全部在用户本机的浏览器/WebAssembly 沙箱中独立完成，零网络流量外发；
2. **断网可用与无服务器依赖**：
   - 模型在初次使用加载完成后，永久缓存在客户端离线存储中，弱网、飞行模式或无网环境下依旧稳定出字；
3. **开源轻量零限制**：
   - 彻底摆脱第三方商业语音转写 API 的调用次数与并发限制，用户享有绝对的数据自主权。
